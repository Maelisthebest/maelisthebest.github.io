2. Verfügbare Elemente

Anleitung: Einmaliges Setup

  1. Lade den Ordner mit deiner Erweiterung herunter und entpacke ihn.
  2. Öffne in Chrome/Edge die Seite chrome://extensions/.
  3. Aktiviere oben rechts den Entwicklermodus.
  4. Klicke oben links auf Entpackte Erweiterung laden und wähle deinen Ordner aus.
  5. Kopiere die 32-stellige ID deiner Erweiterung.
  6. Füge die ID rechts in das Eingabefeld ein und klicke auf Speichern.
